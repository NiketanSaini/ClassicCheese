# ClassicCheese

A collection of proof-of-concept implementations for classic industry problems and patterns, built for learning and experimentation.

## About

This repository hosts multiple independent projects, each tackling a well-known problem or pattern (e.g. rate limiting, caching, job queues, distributed locks, pub/sub, etc.). Every project lives in its own directory with its own dependencies and README.

## Tech Stack

Projects in this repo are built with a mix of:

- Go
- Node.js
- Next.js
- React
- TypeScript

## Structure

Each subdirectory is a standalone POC:

```
ClassicCheese/
├── project-one/
├── project-two/
└── ...
```

Refer to each project's own README for setup and run instructions.
